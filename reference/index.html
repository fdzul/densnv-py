    Effective reproductive number (Rt) of dengue.

    Rt for the country, a state, a municipality or a locality, from the daily incidence of the SINAVE cases and a parametric serial interval (Cori et al. 2013), as rt_dengue() of densnv in R.

    Parameters:

    Name Type Description Default
    dataset DataFrame

    SINAVE dengue dataset (e.g. densnv.read_sinave("DENGUE2_.txt")). It needs FEC_INI_SIGNOS_SINT, ESTATUS_CASO and, depending on level and place, CVE_EDO_*, CVE_MPO_* and CVE_LOC_*.

    		 required
    level ('country', 'state', 'municipality', 'locality')
    		"country"
    place ('REP', 'RES')

    Place used to select the cases: of report (default; the cases are geocoded with it) or of residence. In non-endemic areas the cases are reported where they were exposed, so the place of report is the place of transmission.

    		 "REP"
    cve_edo (str, int or list)

    INEGI keys of the state, municipality and locality. cve_mpo and cve_loc can be lists of the same length (pairs).

    		 None
    cve_mpo (str, int or list)

    INEGI keys of the state, municipality and locality. cve_mpo and cve_loc can be lists of the same length (pairs).

    		 None
    cve_loc (str, int or list)

    INEGI keys of the state, municipality and locality. cve_mpo and cve_loc can be lists of the same length (pairs).

    		 None
    status_caso int or list of int

    1 probable, 2 confirmed.

    		 (1, 2)
    ref_date str or date

    Reference date; by default the latest date of onset of the cases.

    		 None
    period_days int

    Days, up to ref_date, of the daily incidence (default 365).

    		 365
    window_days int

    Days, up to ref_date, of the window whose Rt gives the phase of the outbreak (default 21).

    		 21
    mean_si float

    Mean and standard deviation (days) of the serial interval (21, 6.1).

    		 21
    std_si float

    Mean and standard deviation (days) of the serial interval (21, 6.1).

    		 21
    plot bool

    Draw the Rt curve (matplotlib).

    		 True

    Returns:

    Type Description
    dict

    rt (Rt of the weekly sliding windows with at least 10 cases, or None), rt_ventana (Rt of the window, its 95% credible interval and the phase: "En ascenso", "Estable", "En descenso" or "Sin estimar"), incidencia (daily incidence), area (name of the area) and figure (or None).
    Notes

    The curve uses weekly sliding windows with at least 10 cases that start at least mean_si + 2 * std_si days after the first date of onset of the dataset or of the period, whichever is later; before it the infectiousness of the previous cases is unknown and Rt is overestimated. The last days are usually incomplete (delay of report), which lowers Rt at the end.

    Rt with a parametric serial interval (EpiEstim::estimate_R(), method "parametric_si").

    Parameters:

    Name Type Description Default
    incidence array - like

    Daily incidence (cases per day, consecutive days). As in EpiEstim, the cases of the first day are taken as imported.

    		 required
    t_start array-like of int

    Start and end (1-based, inclusive) of each time window.

    		 required
    t_end array-like of int

    Start and end (1-based, inclusive) of each time window.

    		 required
    mean_si float

    Mean and standard deviation (days) of the serial interval.

    		 21
    std_si float

    Mean and standard deviation (days) of the serial interval.

    		 21
    mean_prior float

    Mean and standard deviation of the gamma prior of Rt.

    		 5
    std_prior float

    Mean and standard deviation of the gamma prior of Rt.

    		 5

    Returns:

    Type Description
    DataFrame

    One row per window: t_start, t_end, mean, std and the quantiles q025 ... q975 of the posterior of Rt.

    Discretised serial interval: gamma distribution shifted by one day.

    Same as EpiEstim::discr_si().

    Active dengue transmission foci and diagnosis of the epidemiological scenario.

    Python version of mp_active_foci() of densnv (R). It identifies the active transmission foci of a locality with DBSCAN (window) or ST-DBSCAN, delimits the transmission and control zones, selects the blocks to treat, tests the space-time interaction with the Knox test (global and by focus), estimates Rt with :func:rt_dengue and diagnoses the epidemiological scenario with the operational strategy.

    Parameters:

    Name Type Description Default
    geocoded_dataset DataFrame

    Geocoded cases with long, lat (EPSG:4326), ESTATUS_CASO and FEC_INI_SIGNOS_SINT; for Rt also the CVE_*_REP (or RES) keys.

    		 required
    cve_edo str or int

    INEGI state key of the locality.

    		 required
    locality str

    Name of the locality (as in rgeomex.extract_locality()).

    		 required
    status_caso int or list of int

    1 probable, 2 confirmed.

    		 (1, 2)
    spatial_scale float

    Spatial window in metres (flight range of Aedes aegypti, 400).

    		 400
    temporal_scale int

    Temporal window in days (intrinsic + extrinsic incubation, 21).

    		 21
    min_cases int

    Minimum cases in the space-time window to define a focus (3).

    		 3
    buffer_m float

    Buffer of the control zone around the transmission zone (200 m).

    		 200
    ref_date str or date

    Reference date; by default the latest onset in the locality.

    		 None
    method ('window', 'st-dbscan')

    Fixed window or space-time DBSCAN (new and persistent foci).

    		 "window"
    n_sim int

    Permutations of the Knox test (0 skips it).

    		 999
    perm_days int

    Days, up to ref_date, of the cases used by the Knox test and by ST-DBSCAN (>= temporal_scale).

    		 365
    alpha float

    Significance level (Holm-adjusted p-value by focus; Poisson test).

    		 0.05
    seed int

    Seed of the permutations.

    		 None
    place ('REP', 'RES')

    Place of the cases used for Rt.

    		 "REP"
    mean_si float

    Serial interval for Rt (21, 6.1 days).

    		 21
    std_si float

    Serial interval for Rt (21, 6.1 days).

    		 21
    capacity_cases float

    Operational capacity: cases per week the brigades can work.

    		 None
    coverage_min float

    Coverage of the locality by the recent cases to consider them dispersed; by default 0.40 with 21 days, 0.50 with 28 and linear in between.

    		 None
    foci_min float

    Proportion of the recent cases in foci from which the cases are also considered dispersed (0.9).

    		 0.9

    Return the interactive map (folium) in map.

    save bool

    		 False
    dir str

    Folder where the blocks are saved.

    		 './'
